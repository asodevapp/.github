## Why ASO.dev

- **No artificial limits.** Keywords, competitor apps and ranking data are not paid add-ons, and API automation
  doesn't burn through a quota.
- **Both stores in one place.** App Store Connect and Google Play side by side, in the same workspace.
- **Your keys stay on your device.** Credentials live in your device's secure storage, and requests go straight from
  your computer to Apple and Google — never through our servers. [How it works →](https://aso.dev/getting-started/security/)
- **Built for AI.** A local MCP server and open Agent Skills let Claude, Cursor and other assistants work with your
  real metadata. You review and save.
- **Native everywhere.** macOS, Windows, Linux, iOS, iPadOS and Android. No browser tab to lose.

## AI Companion and Agent Skills

**AI Companion** is an MCP server that runs inside ASO.dev on your machine (`http://localhost:42111`). Connect Claude
Desktop, Cursor, VS Code (Cline, Roo Code, Copilot Chat), Gemini or Antigravity, and your assistant can read and draft
metadata for the current workspace. Nothing goes live without you: review the changes and save them in ASO.dev.
[Set it up →](https://aso.dev/metadata/mcp-server/)

**[ASO.dev Agent Skills](https://github.com/asodevapp/skills)** are 27 open workflows for ASO audits, keyword research,
competitor analysis, metadata and localization, reviews, in-app purchases and subscriptions, CPP/PPO, In-App Events,
release notes and more. Install them in Claude Code:

```text
/plugin marketplace add asodevapp/skills
/plugin install asodev-skills@asodev-skills
```

Using Codex, Cursor or Antigravity? Copy the skill folders as described in the
[skills repository](https://github.com/asodevapp/skills). Need raw data for your own scripts? See the
[Developer API (alpha)](https://aso.dev/tools/api/).
